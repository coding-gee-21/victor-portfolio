DS1302 Real-Time Digital Clock & Alarm System

Precision timing architecture with software debouncing, custom interrupt-based alarms, and dual 12/24-hour LCD interface.

1. Engineering Concept & Problem Statement

Standard microcontroller internal timers suffer from noticeable frequency drift due to temperature variance and clock cycle inaccuracy. This project solves that limitation by interfacing a dedicated Real-Time Clock (RTC) integrated circuit (DS1302) with an ATmega328P microcontroller.

The system maintains accurate sub-second timekeeping backed by a CR2032 coin-cell battery during main system power dropouts, ensuring uninterrupted operation in power-sensitive deployments.

2. Hardware & Circuit Architecture

  • RTC IC: DS1302 real-time clock operating over a 3-wire synchronous serial communication bus (CE, I/O, SCLK).
  • Time Base: 32.768 kHz quartz crystal oscillator connected directly to X1/X2 pins for high clock accuracy.
  • Display Interface: 16x2 character LCD driven via a 4-bit parallel data interface to conserve microcontroller I/O pins.
  • User Input Matrix: Tactile push buttons configured with internal pull-up resistors for menu selection, time setting, and alarm configuration.

3. Firmware Engineering & Debugging

Challenge 1: Tactile Switch Contact Bounce

Diagnosis: Mechanical button presses produced rapid voltage spikes, causing multiple false register triggers in state selection routines.

Solution: Implemented software debouncing logic utilizing a 50ms time-sampling delay before validating button state transitions.

Challenge 2: Display Screen Flickering

Diagnosis: Redrawing the entire LCD screen on every loop execution created visible screen strobe artifacts.

Solution: Restructured LCD update cycles to write only changed time digits when seconds or menu states changed.

4. Live Embedded C/C++ Firmware

#include <Wire.h>
#include <LiquidCrystal.h>
#include <DS1302.h>

// Pin initialization for DS1302 (CE, IO, SCLK)
DS1302 rtc(2, 3, 4);
LiquidCrystal lcd(7, 8, 9, 10, 11, 12);

void setup() {
  lcd.begin(16, 2);
  rtc.halt(false);
  rtc.writeProtect(false);
}

void loop() {
  Time t = rtc.getTime();
  
  // Software Debounced LCD Refresh
  lcd.setCursor(0, 0);
  lcd.print("TIME: ");
  lcd.print(rtc.getTimeStr());
  
  lcd.setCursor(0, 1);
  lcd.print("DATE: ");
  lcd.print(rtc.getDateStr());
  
  delay(500); // 500ms Update Sampling Window
}
