1. Engineering Concept & Problem Statement

Conventional decorative lighting systems run static, pre-programmed lighting sequences that lack responsiveness to environmental ambient sounds. This engineering project presents a real-time sound-reactive lighting driver capable of analyzing live room acoustics, detecting rhythm beats, and executing dynamic light chase routines synchronized to audio amplitude peaks.

2. Hardware Architecture & Signal Chain

  • Acoustic Sensing: Microphone sensor module with integrated operational amplifier for signal boosting.
  • Infrared Receiver: HS0038 IR receiver module for manual remote parameter modification.
  • Microcontroller Core: Microcontroller reading analog acoustic signals through 10-bit Analog-to-Digital Converter (ADC) channels.
  • Output Stage: Multi-channel NPN transistor switching circuit controlling power flow to multi-segment LED strips.

3. Firmware Logic & Calibration

Challenge 1: Ambient Background Noise Interference

Diagnosis: Background noise created false beat detections, causing the LEDs to flicker continuously even during quiet passages.

Solution: Developed a dynamic thresholding algorithm in C firmware that continuously samples average ambient noise and sets the trigger point 15% above background noise levels.

Challenge 2: Real-Time IR Decoding Interrupts

Diagnosis: IR remote decoding delays were causing missed beat samples during high-speed audio transitions.

Solution: Reorganized software logic to handle IR signal processing via hardware pin interrupts without blocking the primary audio-sampling loop.

4. Live Embedded C/C++ Firmware

#include <Arduino.h>

// Pin Definitions
#define MIC_PIN A0        // Electret Microphone via Op-Amp
#define IR_PIN 2          // HS0038 IR Receiver
#define LED_STRIP_1 3     // PWM Output Channel 1
#define LED_STRIP_2 5     // PWM Output Channel 2
#define LED_STRIP_3 6     // PWM Output Channel 3

// Amplitude Threshold Variables
volatile int ambientNoise = 0;
volatile int beatThreshold = 0;

void setup() {
  Serial.begin(9600);
  pinMode(MIC_PIN, INPUT);
  pinMode(IR_PIN, INPUT);
  pinMode(LED_STRIP_1, OUTPUT);
  pinMode(LED_STRIP_2, OUTPUT);
  pinMode(LED_STRIP_3, OUTPUT);

  // Calibrate Ambient Noise Floor at Startup
  calibrateAmbientNoise();
}

void loop() {
  int signalLevel = analogRead(MIC_PIN);

  // Dynamic Amplitude Threshold Detection
  if (signalLevel > beatThreshold) {
    int beatIntensity = map(signalLevel, beatThreshold, 1023, 0, 255);
    triggerLightPattern(beatIntensity);
  }

  // IR Remote Override (Non-Blocking Interrupt)
  handleIRRemote();

  // Continuous Ambient Noise Recalibration
  recalibrateThreshold();
}

void calibrateAmbientNoise() {
  long total = 0;
  for (int i = 0; i < 100; i++) {
    total += analogRead(MIC_PIN);
    delay(5);
  }
  ambientNoise = total / 100;
  beatThreshold = ambientNoise + (ambientNoise * 0.15); // 15% Above Background
}

void triggerLightPattern(int intensity) {
  int pwmVal = constrain(intensity, 0, 255);
  analogWrite(LED_STRIP_1, pwmVal);
  analogWrite(LED_STRIP_2, pwmVal / 2);
  analogWrite(LED_STRIP_3, pwmVal / 4);
}

void recalibrateThreshold() {
  static unsigned long lastCalibration = 0;
  if (millis() - lastCalibration > 5000) { // Recalibrate every 5 seconds
    calibrateAmbientNoise();
    lastCalibration = millis();
  }
}
